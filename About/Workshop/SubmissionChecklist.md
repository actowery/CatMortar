# Steam Workshop submission checklist

- Title: `Cat Mortar`
- Visibility: `Public`
- Tags: `Weapons`, `Gameplay`, `Fun`
- Game versions: `1.6`, `1.7`
- Description: paste `SteamDescription.md` as BBCode.
- Primary preview: `../Preview.png` (512 × 512, under 1 MB).
- Gallery: use only `Hero.png`, showing the cat-themed ground mortar launching one cat.
- Upload only the CI-tested `CatMortar.zip` package if a manual archive upload is requested.
- Verify the page links to `https://github.com/actowery/CatMortar` before publishing.
